# Chat App

## Description

A simple real-time chat application where users can sign up, log in, and chat within specific rooms. Built to demonstrate real-time bidirectional communication and database persistence.

## Tech Stack

- **Backend**: Node.js, Express, Socket.io

- **Database**: MongoDB, Mongoose

- **Frontend**: React, Tailwind CSS

## Features

- **JWT-based authentication**

- **Join and leave specific chat rooms**

- **Real-time group and private messaging**

- **"User is typing..." indicators.**
